# AC Hardware website

Website for AC Hardware, One-Stop Tools Station and TOTAL tools dealer in Mauritius.

Live: https://webluxe.github.io/ACHardware-Website/

- Plain HTML, CSS and JavaScript. No build step.
- Shop details, aisles and products (name, aisle, photo, price) live in `config.js`.
- Prices shown are examples until `demoPrices: false` is set in `config.js` with real prices.
- Address, opening hours, WhatsApp and map are blank in `config.js` until the shop confirms them.
